Surf Condition Model

Technical reference — wave height and quality calculations

1. Wave Height Pipeline

The wave height at each beach is computed through a four-stage pipeline:

offshore swell
  → 1. Refraction (Snell's law for parallel contours)
  → 2. Diffraction (cosine-squared Fresnel, period-dependent)
  → 3. Shoaling (linear wave theory, Newton-Raphson wavenumber solver)
  → 4. Sandbar check (bar top speed bump, if bar present)
  → 5. Iterative breaker loop (H_b / h_b = 0.78)
  → breaker height (= face height)

The Sydney coastline general shore-normal is roughly ESE (100°). Each beach uses its own aspect from beaches.json as the local shore-normal for refraction.

1.1 Combined Swell Energy

All available swell components (primary, secondary, tertiary) are evaluated for each beach. Their effective heights (after the full pipeline) are combined via root-sum-square (RSS) energy addition:

H_combined = √(H₁² + H₂² + H₃²)

The dominant component (largest effective height contribution) sets the wave period, direction, and quality character.

1.2 Refraction (Snell's Law for Parallel Contours)

As waves approach the coast, their phase velocity decreases in shallower water, causing the wave rays to bend toward the shore-normal. This is computed using Snell's law:

sin(α₁₀) / c₁₀ = sin(α₀) / c₀
    where:
      c₀ = gT / 2π  (deep water celerity)
      c₁₀ = phase velocity at 10m depth (from shoaling solver)
      α₀ = angle between deep-water ray and shore-normal
      α₁₀ = refracted angle at 10m depth

The refracted direction replaces the raw offshore direction in both the diffraction calculation and the attack angle. This prevents the model from using an offshore ray angle that's no longer valid by the time the wave reaches the headland shadow zone.

For a typical S swell (180°) at an SE beach (135°), the 45° offshore angle refracts to approximately 21° at 10m depth.

1.3 Headland Diffraction

Each beach has a swell window defined by its aspect angle and left/right offsets. Swell arriving inside the window passes without loss. Outside the window, energy is reduced by a cosine-squared Fresnel diffraction model, period-dependent:

Kd = cos²(θ · π/2 · 90°)
    θ = shadow_angle · (10 / T)   (period-adjusted)
    Kd ∈ [0.05, 1.0]

1.4 Sandbar Speed Bump

If the beach has a sandbar (defined by bar_depth_cd in beaches.json), the bar acts as a speed bump in the depth profile. Before the iterative breaker loop, the model checks whether the wave would break at the bar top:

bar_top = bar_depth_cd + tide_height
    if bar_top < start_depth:
        Ks(bar_top) = √(cg0 / cg(bar_top))
        H = Hoffshore · Ks(bar_top) · Kd
        if H / bar_top >= 0.78:
            → bar-induced break     (was_bar_break = True)

If the wave trips at the bar, this is a bar-induced break. The wave breaks over the bar (typically hollow, pitching), reforms in the deeper trough behind the bar, and runs up the beach face as a smaller wave. If the wave doesn't trip at the bar, it passes over and continues to the beach-face break via the normal loop.

This is tide-dependent: low tide exposes the bar (shallower bar top = more likely to trip), high tide deepens the bar (wave passes over it).

1.5 Shoaling + Iterative Breaker Loop

This replaces the old fixed-depth shoaling at 10m, the slope modifier, the period-based face height multiplier, and the depth-limited cap — all with one physical calculation.

Starting from 10m depth (plus tide height), the wave steps down toward the beach in 0.5m increments. At each step, the shoaling coefficient is computed from linear wave theory (Newton-Raphson wavenumber solver), and the breaker criterion is checked:

h = 10.0 + tide_height
    while h >= 0.5:
        Ks = √(cg0 / cg(h))   (shoaling to depth h)
        H = Hoffshore · Ks · Kd
        if H / h >= 0.78:          ← depth-limited breaker criterion
            return H               ← this is the breaker height (face height)
        h -= 0.5

The shoaling coefficient uses the dispersion relation solved via Hunt's approximation + 3 Newton-Raphson iterations:

ω² = gk · tanh(kh)
    Ks = √(cg0 / cg)
    cg = n · ω/k,  n = 0.5(1 + 2kh / sinh(2kh))

1.6 Wind Hold-Up Boost

Offshore wind hitting the wave face head-on holds the wave up, making it taller. A post-breaker wind boost is applied to the breaker height:

wind_vs_swell = |wind_dir − swell_dir| (wrapped to 0–180°)
    hold_up = (1 − cos(wind_vs_swell)) / 2
    strength = clamp((wind_speed − 5) / 35, 0, 1)
    wind_boost = 1.0 + hold_up · strength · 0.25
    face_height = breaker_height · wind_boost

Wind opposite to the swell source (180° apart) = hits the face directly = max 25% boost. Wind aligned with the swell source (0°) = off the back = no boost.

1.7 Height Range from Spectral Width

When the swell spectrum is broad, heights display as a range. The Tp/Tm gap proxies spectral width:

ratio = Tp / Tm  (clamped to 2.5)
    lower_mult = max(0.75, 1.0 − (ratio − 1.0) · 0.1)
    upper_mult = 1.0 + (ratio − 1.0) · 0.4
    H_range = [H_eff · lower_mult, H_eff · upper_mult]

2.2.1 Wind Quality (bwq)

Two-component model — beach-relative wind (onshore/offshore) blended with swell-relative wind (face/back alignment):

2026-07-27 fix: The beach-relative values were previously inverted. Offshore wind should be the highest quality (holds the wave face up) and onshore wind the lowest (crumbles the wave). Waves break toward the beach, so the wave face is always shoreward.

// Beach-relative: exponential speed penalty by direction band
    // Waves break toward the beach, so the wave face is shoreward:
    //   Offshore wind (from behind beach, diff ≈ 180°) = hits the face = GOOD
    //   Onshore wind (from ocean, diff ≈ 0°) = hits the back = BAD
    diff ≤ 30° (onshore):     beach_q = 0.25 - (speed/80)²
    diff ≤ 60° (cross-on):    beach_q = 0.35 - (speed/100)²
    diff ≤ 120° (cross):     beach_q = 0.60 - (speed/120)²
    diff ≤ 150° (cross-off): beach_q = 0.85 - (speed/150)²
    else (offshore):                beach_q = 1.00 - (speed/200)²

    // Swell-relative: wind opposite to swell source = on face = boost
    wind_vs_swell = |wind_dir − swell_dir| (wrapped to 0–180°)
    swell_mod = 0.9 − 0.3 · cos(wind_vs_swell)
    // cos(0°)=1 → off back → 0.6 (penalty)
    // cos(180°)=−1 → on face → 1.2 (boost)

    bwq = beach_q · (1 − blend) + (beach_q · swell_mod) · blend
    blend = min(speed / 30, 1) · 0.4

2.2.2 Breaker Quality (brk)

Bar-induced break (when was_bar_break = True): quality depends on whether the wave reforms cleanly in the trough behind the bar.

reformed_height = Hbreaker · 0.5   (wave loses ~50% over the bar)
    trough_depth = bar_trough_depth_cd + tide_height
    if reformed_height < 0.78 · trough_depth:
        quality = 0.95 (good bar) or 0.85 (average bar)   ← clean reform, hollow lip
    else:
        quality = 0.25                                      ← close-out, unrideable

Beach-face break (no bar, or wave passed over the bar): quality depends on tide height relative to slope-dependent ideal ratio.

depth = tide_height + 1.0m
    delta = Hbreaker / max(depth, 0.5)
    ideal = 0.3 + 0.2 · slope_modifier
    quality = 1.0 − min(|delta − ideal| · 2.0, 1.0)

2.2.3 Embayment Factor (embay)

2026-07-27 update: Narrow bays now get a 5% quality boost on small swells (ratio < 0.5), reflecting the energy-focusing effect that makes waves feel punchier than they would on an open beach.

openness = 0.25 (narrow) or 0.9 (wide)
    energy = Hbreaker · T
    capacity = 50 · openness
    ratio = energy / capacity
    if ratio < 0.5:
        return 1.05 (narrow) or 1.0 (wide)   ← energy focus boost
    else:
        piecewise 0.9 → 0.3

2.2.4 Tide Factor (tdv)

2026-07-27 update: Trend bonus changed from asymmetric (+0.1 rising, -0.05 falling) to symmetric ±0.075 to match the equal-and-opposite nature of tidal push/suck.

base: < 0.4m → 0.6, 0.4–0.8m → 0.8, 0.8–1.2m → 0.9, > 1.5m → 0.5
    trend: rising +0.075, falling −0.075

2.2.5 Wind-Sea Quality (wsq)

wsr = Hwind_wave / Hdominant_swell
    wsq = 1.0 if wsr ≤ 0.25, else max(0.7, 1 − (wsr − 0.25) / 2.5)

2.2.6 Swell Variability Quality (sv)

2026-07-27 new: Broad-spectrum (messy) conditions penalised via Tp/Tm gap. A narrow spectrum means organised swell with clean lines. A broad spectrum means mixed energy and poorer quality.

ratio = Tp / Tm  (clamped to 2.5)
    sv = max(0.70, 1.0 − (ratio − 1.0) · 0.2)
    // ratio=1.0 (tight) → 1.00, ratio=1.5 (moderate) → 0.90, ratio=2.5 (messy) → 0.70

2.2.8 Bar Quality Modifier (bar)

Uses each beach's bar_depth_cd (bar top depth at chart datum) to shift the tide windows to match the actual bar depth, and bar_quality to adjust the sweet spot width.

depth_over_bar = tide_height − bar_depth_cd
    // Negative = bar exposed, Positive = water over the bar

    // Good bar (Dee Why, North Curl Curl, Freshwater):
    < −0.5m → 0.90       ← exposed, close-out
    −0.5–0.2m → 0.90→1.15  ← ramping up
    0.2–0.8m → 1.15        ← sweet spot
    0.8–1.5m → 1.15→0.85  ← tapering off
    > 1.5m → 0.85            ← too deep, fatten up

    // Average bar: narrower sweet spot, peaks at 1.05
