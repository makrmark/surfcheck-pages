Surf Condition Model

Technical reference — wave height and quality calculations

1. Wave Height

1.1 Combined Swell Energy

All available swell components (primary, secondary, tertiary) are evaluated for each beach. Their effective heights (after shoaling and diffraction) are combined via root-sum-square (RSS) energy addition:

H_combined = √(H₁² + H₂² + H₃²)

Components with negligible height (< 0.01m after diffraction) are excluded. The dominant component (largest effective height contribution) sets the wave period, direction, and quality character for the beach.

1.2 Headland Diffraction

Each beach has a swell window defined by its aspect angle and left/right offsets. Swell arriving inside the window passes without loss. Outside the window, energy is reduced by a cosine-squared Fresnel diffraction model:

Kd = cos²(θ · π/2 · 90°)
    where θ = shadow_angle · (10 / T)
    Kd ∈ [0.05, 1.0]

Period dependence: Longer period swells diffract more (wrap around headlands more effectively). The effective shadow angle is scaled by a period factor: 10 / max(T, 3).

1.3 Shoaling

Wave shoaling is computed using linear wave theory at a reference depth of 10m. The dispersion relation is solved via Newton-Raphson iteration (3 iterations) to obtain the wavenumber k, then the shoaling coefficient is:

Ks = √(cg0 / cg)
    cg0 = group velocity in deep water
    cg = n · c at 10m depth
    n = 0.5 · (1 + 2kh / sinh(2kh))
    Ks ≥ 1.0 · slope_modifier

Slope modifier: The per-beach slope modifier is inverted for shoaling. Flat beaches shoal waves more over their longer approach zone, while steep reflective beaches transition faster and shoal less:

SlopeQuality modifierShoaling modifier (inverted)
Steep1.150.87 (1/1.15)
Moderate1.001.00
Flat0.851.18 (1/0.85)
The slope modifier has a dual role: it amplifies shoaling for flat beaches (inverted) while also influencing breaker quality (normal direction). Steep beaches produce punchier waves at higher height-to-depth ratios.

1.4 Depth-Limited Breaking Cap

After shoaling and diffraction, the effective height is capped by the depth-limited breaker criterion:

H ≤ γ · h
    γ = 0.78 (breaker index)
    h = 10m (reference depth)
    H_max ≈ 7.8m

This only activates for extreme swells (>~6m at the 10m contour). For typical Sydney surf (1–4m), no cap is applied.

1.5 Face Height Conversion

The visible face of a breaking wave is significantly taller than the significant wave height. Face height is estimated from the nearshore effective height using a period-based multiplier:

face_height = H_effective · period_factor · wind_boost
    period_factor = 0.7 + T · 0.07
    period_factor ∈ [1.0, 2.0]
    total_multiplier ∈ [1.0, 2.5]

1.6 Wind Hold-Up Boost

Offshore wind hitting the wave face head-on holds the wave up, making it taller and steeper. A wind boost multiplier is computed from wind speed and the angle between wind direction and swell source direction:

wind_vs_swell = |wind_dir − swell_dir| (wrapped to 0–180°)
    hold_up = (1 − cos(wind_vs_swell)) / 2
    strength = clamp((wind_speed − 5) / 35, 0, 1)
    wind_boost = 1.0 + hold_up · strength · 0.25

Wind opposite to the swell source (180° apart) hits the wave face directly → max hold-up. Wind aligned with the swell source (0°) goes off the back → no boost. The boost ramps linearly between 5–40 km/h, capping at 25% additional face height.

1.7 Height Range from Spectral Width

When the swell spectrum is broad (mixed conditions), heights are displayed as a range rather than a single value. The gap between peak period (Tp) and mean period (Tm) is used as a proxy for spectral width:

ratio = Tp / Tm  (clamped to 2.5)
    lower_mult = max(0.75, 1.0 − (ratio − 1.0) · 0.1)
    upper_mult = 1.0 + (ratio − 1.0) · 0.4
    H_lower = H_effective · lower_mult
    H_upper = H_effective · upper_mult

2. Surf Quality Rating

2.1 Wave Height Score

whs = min(5, 5 · (H_effective / 1.83)0.85)
    where 1.83m = 6ft (overhead reference)

Beyond overhead, the height score plateaus and quality factors differentiate.

2.2 Wave Quality (7 Factors, Multiplicative)

wq = bwq · embay · brk · wsq · gs_factor · bar

2.2.1 Wind Quality (bwq)

Two-component model blending beach-relative wind (onshore/offshore) with swell-relative wind (face/back alignment):

// Beach-relative: exponential speed penalty by direction band
    beach_q = f(|wind_dir − beach_aspect|, speed)
    // Bands: 0–30° (offshore) → 1.0 − (s/80)²
    //        30–60° (cross-off) → 0.8 − (s/100)²
    //        60–120° (cross) → 0.5 − (s/120)²
    //        120–150° (cross-on) → 0.3 − (s/150)²
    //        150–180° (onshore) → 0.1 − (s/200)²

    // Swell-relative: wind opposite to swell source = on face = boost
    wind_vs_swell = |wind_dir − swell_dir| (wrapped to 0–180°)
    swell_mod = 0.9 − 0.3 · cos(wind_vs_swell)
    // cos(0°)=1 → off back → 0.6 (penalty)
    // cos(180°)=−1 → on face → 1.2 (boost)

    bwq = beach_q · (1 − blend) + (beach_q · swell_mod) · blend
    blend = min(speed / 30, 1) · 0.4

The blend weights swell alignment more heavily at higher wind speeds.

2.2.2 Breaker Quality (brk)

Estimates how cleanly the wave breaks from the height-to-depth ratio at the break line:

depth = tide_height + 1.0m
    delta = H_effective / max(depth, 0.5)
    ideal = 0.3 + 0.2 · slope_modifier
    // steep: ideal=0.53, moderate: ideal=0.50, flat: ideal=0.47
    quality = 1.0 − min(|delta − ideal| · 2.0, 1.0)

Steeper beaches have a higher ideal height-to-depth ratio — they produce punchier, more critical waves. Flatter beaches break at lower ratios.

2.2.3 Embayment Factor (embay)

Measures how well the beach's physical layout accommodates the incoming swell energy:

openness = 0.25 (narrow) or 0.9 (wide)
    energy = H_effective · T
    capacity = 50 · openness
    ratio = energy / capacity
    piecewise: ratio < 0.5 → 1.0
               ratio < 1.0 → 0.9 → 0.7
               ratio < 2.0 → 0.7 → 0.5
               else → 0.5 → 0.3 (close-out)

Narrow beaches (Freshwater) close out on big swells but produce punchy peaks on small days. Wide beaches (Long Reef, Curl Curl) handle size better.

2.2.4 Tide Factor (tdv)

base: < 0.4m → 0.6
         0.4–0.8m → 0.8
         0.8–1.2m → 0.9 (sweet spot)
         1.2–1.5m → 0.7
         > 1.5m → 0.5
    trend: rising +0.1, falling −0.05

2.2.5 Wind-Sea Quality (wsq)

Penalises quality when local wind chop exceeds 25% of the dominant swell height:

wsr = H_wind_wave / H_dominant_swell
    wsq = 1.0 if wsr ≤ 0.25
    wsq = max(0.7, 1 − (wsr − 0.25) / 2.5) if wsr > 0.25

2.2.6 Groundswell Quality Factor (gs_factor)

Rewards long-period organised groundswell and penalises short-period wind-driven chop:

PeriodFactorMeaning
≥ 12s1.30Proper long-period groundswell, clean organised lines
≥ 10s1.15Decent groundswell, good energy
≥ 8s1.00Mixed, some organisation
≥ 6s0.75Short-period windswell, weak/pitchy
< 6s0.50Wind-driven chop

2.2.7 Bar Quality Modifier (bar)

Tide-dependent quality boost for beaches with sandbars (all beaches except Long Reef, which is a flat rock platform):

tide < 0.3m → 0.95 (exposed bar, close-out)
    tide 0.3–0.8m → 1.00 → 1.15 (ramping up)
    tide 0.8–1.3m → 1.15 (sweet spot)
    tide 1.3–1.8m → 1.15 → 0.90 (tapering off)
    tide > 1.8m → 0.90 (too deep over the bar)

3. Final Rating

The final rating is a decoupled combination of height score and quality:

height_part = whs · 0.4
    quality_part = wq · 5.0 · 0.6
    rating = clamp(height_part + quality_part, 0, 5)

Height contributes 40%, quality 60%. This decoupling prevents big messy waves from rating well just because they're big, and lets small clean days (e.g. 0.3m glassy) rate properly (~3.1 vs ~1.0 under the old height-only model).
